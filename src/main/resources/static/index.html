Spracovanie

Kroky idú po poradí. Ďalší krok je dostupný, keď predchádzajúci skončí úspešne.

  1. Vytvorenie XML
    Uloží údaje z formulára. Hotový XML súbor môžete aj načítať: vyplní formulár a uloží sa bez zmeny.
  2. Overenie voči XSD
    Overí uložený XML súbor voči schéme protokol.xsd.
  3. Transformácia do HTML
    Vytvorí HTML podľa protokol.xsl. Dostupné po úspešnom overení.
  4. Elektronický podpis
    Jedným podpisom XAdES-BES podpíše XML (s XSD a XSL) a PDF a uloží kontajner ASiC-E. Dostupné po úspešnom overení.
